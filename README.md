# Discord Invite List Bot

A simple Discord bot that lets you post a custom embed with a button.  
When users click the button, they see your list of invites.

## Features
- Editable button name
- Editable numbered list
- Editable embed title & description
- Role-based permissions

## Setup

1. Clone or download this repo
2. Install requirements:
   ```bash
   pip install -r requirements.txt
